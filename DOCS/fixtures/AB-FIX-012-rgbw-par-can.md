# AB-FIX-012 - RGBW Par Can

Generic RGBW par profile for direct red, green, blue, white, and master dimmer control.

## DMX Mode

| Channel | Name | Range | Function |
| --- | --- | --- | --- |
| 1 | Red | 0-255 | 0-100% red |
| 2 | Green | 0-255 | 0-100% green |
| 3 | Blue | 0-255 | 0-100% blue |
| 4 | White | 0-255 | 0-100% white |
| 5 | Dimmer | 0-255 | 0-100% master dimmer |

## Notes

- Use this as a starter profile for simple RGBW wash lights when the exact manual is not yet imported.
- This lives in the same canonical ArtBastard fixture library as the source-backed hardware profiles.
