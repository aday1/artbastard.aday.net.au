# AB-FIX-010 - Generic Dimmer

Generic one-channel profile for a dimmer pack, single-channel LED fixture, or any intensity-only DMX device.

## DMX Mode

| Channel | Name | Range | Function |
| --- | --- | --- | --- |
| 1 | Intensity | 0-255 | 0-100% intensity |

## Notes

- Use this when the physical fixture has only one controllable intensity channel.
- This is a canonical ArtBastard fixture-library profile, not a separate legacy built-in template.
