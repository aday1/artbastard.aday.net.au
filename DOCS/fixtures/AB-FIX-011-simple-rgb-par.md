# AB-FIX-011 - Simple RGB Par Can

Generic RGB par profile for direct red, green, blue, and master dimmer control.

## DMX Mode

| Channel | Name | Range | Function |
| --- | --- | --- | --- |
| 1 | Red | 0-255 | 0-100% red |
| 2 | Green | 0-255 | 0-100% green |
| 3 | Blue | 0-255 | 0-100% blue |
| 4 | Dimmer | 0-255 | 0-100% master dimmer |

## Notes

- Use this as a starter profile for simple RGB wash lights when the exact manual is not yet imported.
- This is a canonical ArtBastard fixture-library profile, not a separate legacy built-in template.
