# AB-FIX-013 - Basic Moving Head Spot

Generic ten-channel moving-head spot profile for unconfirmed or temporary moving head fixtures.

## DMX Mode

| Channel | Name | Range | Function |
| --- | --- | --- | --- |
| 1 | Pan | 0-255 | Pan coarse |
| 2 | Tilt | 0-255 | Tilt coarse |
| 3 | Dimmer | 0-255 | 0-100% master dimmer |
| 4 | Red | 0-255 | 0-100% red |
| 5 | Green | 0-255 | 0-100% green |
| 6 | Blue | 0-255 | 0-100% blue |
| 7 | Gobo Wheel | 0-255 | Gobo selection or rotation |
| 8 | Color Wheel | 0-255 | Color wheel selection or rotation |
| 9 | Strobe | 0-255 | Strobe slow to fast |
| 10 | Zoom | 0-255 | Beam zoom |

## Notes

- Use this only as a starter profile until the exact fixture manual is imported.
- This lives in the same canonical ArtBastard fixture library as the source-backed hardware profiles.
