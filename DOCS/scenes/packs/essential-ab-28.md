# Essential 14+14

Default starter pack. Creates 28 APC clip scenes: slots 01-14 on Deck A and the
same 14 look types on Deck B (Deck B gets mirrored color and movement variants
for crossfader work). Leaves slots 15-40 empty on both decks so you can capture
or seed individual looks yourself.
