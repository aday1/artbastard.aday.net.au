Instruments of Photonic Supremacy

"Mes amis, you hold before you not mere software, but symphonic mastery over the electromagnetic spectrum itself."

RACK

Reason-Style Rack UI

Skeuomorphic rack modules, rotary knobs, LEDs, and tab strips across DMX, Super Control, and settings.

AUTO

Automation Workbench

DMX sidebar Automation: per-channel envelopes plus a Renoise-inspired transition tracker with fixture lanes (pan/tilt, RGB, gobo), pages, live hex preview, Env/Grid sync, and BPM/LPB playback.

GRID

Tracker Channel Columns

Grid columns match the page chip list only (no hidden CH 1-8). Add by number, DMX selection, or fixture lanes; Clear all or optional + Pinned. New pages start empty.

CTRL

Remastered Operator Controls

Shared React control kit: XY pads for pan/tilt, gold vertical and horizontal faders, dual-handle range windows, stepped gobo slider, and envelope automation with anime.js outExpo easing. Retired legacy browser range inputs on DMX, fixtures, scenes, mobile, and automation panels.

DMX

Modular DMX Control Page

The 512-channel control surface is split into header, filters, fixture selector, channels viewport, scene controls and a footer status row. Styled faders on every channel card; filtering and pinned-channel logic is unit tested.

MAP

Canvas-First Fixture Setup

Fixture Setup opens on a 1000x600 stage map. Drag or tap a library profile onto the map to create a real patched fixture, assign the next safe DMX start address, save its layout, select it globally, and open the inspector. Top and Side view share coordinates; map selections feed Super Control, APC40 fixture/group selection, Smart Groups, scene seeds, ACT seeds, and Giddy Up.

SCENE

Scenes & Acts

Save and recall scenes; sequence them in the act timeline (clips, gaps, scheduled MIDI/OSC). ACT triggers start/stop acts via MIDI or OSC — separate from Ableton Link tempo sync.

SEED

Optional Show Starters

Default pack fills Deck A and Deck B slots 01-14 only (28 looks), leaving 15-40 for your captures. Operator rows 3-5 pack fills slots 17-40 with pan/tilt-only, color-only, and color+pan/tilt layers that never write dimmer, gobo, or strobe. Seed panels explain each pack, mode, and ACT macro. Extended 40 and Extended 40+40 remain for full-bank fills. One-slot and capture modes add or replace individual clips. Generated content is tagged so reseeding refreshes only ArtBastard-made scenes and ACTS.

SCENE

Timeline Editors

Scene timeline: DMX keyframes (0-255), multi-track, snap, undo. Act timeline: scene clips with start times and gaps. See ACT_TIMELINE.md.

CLIP

Clip Launcher

Session-style grid for live performance. Assign any scene to any cell, see playing/queued/recording states, and stop everything with one button.

CLIP

MIDI Controller Templates

One-click templates for Behringer X-Touch (Mackie mode + scribble strip SysEx labels) and Akai APC40 MK1. Pitch-bend mappings, MIDI Learn for everything else, applied via UI or POST /api/midi/controller-template.

APC40

APC40 MK1 Deep Integration

The full surface, alive. Clip Launch / Session View is Deck A scene slots 1-40; hold SHIFT for Deck B. REC arms save mode for the next grid pad. Record Arm is now Solo Group, Solo/Cue selects fixtures, and Activator selects fixture groups with explicit hardware ON/OFF state. PAN selects all on ON and clears selection on OFF; SEND A/B/C toggle color, pan/tilt, and effects automation on/off. Clip/Track is FULL ON, Device On/Off is BLACKOUT, Master Select is FREEZE DMX, Rec Quantization is a REC alias, MIDI Overdub is panic stop, and Metronome is tap tempo. Track Select intentionally stays unmapped. Out-of-box APC defaults auto-apply on first connect, Focus Mode declutters the manual, and fixture-target tooltips show exactly which selected fixtures each mapped control is driving.

ROLI

Server ROLI XY + Colour Pads

Plug in a joined Roli Lightpad BLOCK pair over one USB cable and the server splits it into two deterministic logical pads: topology index 30 is the primary pan/tilt XY surface, topology index 60 is the colour-wheel pad. LEDs are ACK-paced per pad, with clean crosshair and RGB strip drawing plus role-specific idle motion.

BLKS

Roli Blocks Family Support

Beyond the Lightpad: Seaboard BLOCKs send MPE pitch-bend per finger for continuous pan/tilt rides, and Control BLOCKs become a transport row for ACT triggers. Server ROLI ownership is preferred on Windows; browser Web MIDI remains a fallback when the server has not claimed a pad.

APC4

APC40 LEDs + BPM Header

LEDs now mirror the real latched state: PAN, SEND A/B/C, FULL ON, BLACKOUT, FREEZE, REC/save mode, PLAY/STOP, Deck A/B clips, ACT launch, selected fixtures, selected groups, and Solo Group all repaint from the store. Delayed velocity-zero events are treated as hardware OFF, while immediate releases are ignored. The BPM dashboard stays visible in the top header with source and play-state controls.

OOTB

Out-of-the-Box Mode

Open ArtBastard with no rig, no scenes, no ACTS — and a single seed run gives you a complete demo show: catalog fixtures from the markdown library (`DOCS/fixtures/library/*.md`), 40 named scenes across two APC40 decks, 5 launchable ACTS, and a fully patched stage map. Great for trade-show demos, training, and bug repros.

YAML

Project YAML Round-Trip

Settings → Project YAML exports your live rig as eight hand-editable YAML files (fixtures, groups, scenes, acts, MIDI bindings, Art-Net/OSC config, stage layout & masters, browser presets). Edit in any text editor, commit to git, share with collaborators, and re-import losslessly — a clean install can be fully restored from a single bundle. Groups reference fixtures by stable id so you can rename, reorder, and re-patch without breaking references.

OSC

OSC Integration

Two-way OSC for Super Control, scenes, master faders, and ACT triggers. Use the in-app OSC monitor while mapping. Works with Reaper, QLab, Max/MSP, Pure Data, and any tablet OSC app you configure yourself.

SYNC

Unified Operator Surfaces

One Super Control engine on the fixture page and mobile route. Shared DmxFaderRow controls on the DMX page and a touch pinned-channel strip. Experimental stubs and duplicate touch panels removed.

NET

Art-Net Output

Professional Art-Net distribution across multiple universes. Network interface auto-detection with ICMP ping verification helps you identify USB Ethernet adapters from the Settings panel.

BRIDGE

LAN / Pi Bridge

Hosted at artbastard.aday.net.au? Run artbastard-bridge on a Raspberry Pi on your fixture LAN. The cloud UI drives Art-Net locally; optional Ableton Link on the Pi. Many browsers, one shared show.

TOUCH

Touch Surface

The #/mobile route gives you Super Control and DMX channels with a touch-first layout on phones and tablets. Hash-based deep linking everywhere.

THEME

Live Theme Tuning

HSL sliders and rack presets apply to the UI as you move them. Debounced server sync via /api/appearance; Sync now and Reload UI for multi-client shows. Typography, spacing, and animation speed included.

HELP

In-App Help & Address Sheet

Press Ctrl+H anywhere or open Settings > Help. Covers DMX basics, DIP-switch calculator, MIDI/OSC, ACT triggers, factory reset, controller templates, keyboard shortcuts, troubleshooting, plus a printable PDF address sheet.

TEST

Smoke + Demo Tooling

Vitest unit tests for filtering, ACT triggers, clip launcher and scene capture. Backend smoke script (test:api-contract) plus an automated screenshot and video capture pipeline for the showcase tour.

Quick Start

  1. Clone: git clone https://github.com/aday1/artbastard.aday.net.au.git
  2. Install: npm ci && npm --prefix react-app ci
  3. Run ./start.sh (Linux/macOS) or .\start.ps1 (Windows)
  4. Open http://localhost:3030
  5. Configure your DMX interface in Settings
  6. Need a clean slate? Run with --reset / -Reset
