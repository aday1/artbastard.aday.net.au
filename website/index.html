Instruments of Photonic Supremacy

"Mes amis, you hold before you not mere software, but symphonic mastery over the electromagnetic spectrum itself."

RACK

Reason-Style Rack UI

Skeuomorphic rack modules, rotary knobs, LEDs, and tab strips across DMX, Super Control, and settings.

AUTO

Automation Workbench

DMX sidebar Automation: per-channel envelopes plus a Renoise-inspired transition tracker with fixture lanes (pan/tilt, RGB, gobo), pages, live hex preview, Env/Grid sync, and BPM/LPB playback.

GRID

Tracker Channel Columns

Grid columns match the page chip list only (no hidden CH 1-8). Add by number, DMX selection, or fixture lanes; Clear all or optional + Pinned. New pages start empty.

CTRL

Remastered Operator Controls

Shared React control kit: XY pads for pan/tilt, gold vertical and horizontal faders, dual-handle range windows, stepped gobo slider, and envelope automation with anime.js outExpo easing. Retired legacy browser range inputs on DMX, fixtures, scenes, mobile, and automation panels.

DMX

Modular DMX Control Page

The 512-channel control surface is split into header, filters, fixture selector, channels viewport, scene controls and a footer status row. Styled faders on every channel card; filtering and pinned-channel logic is unit tested.

SCENE

Scenes & Acts

Save and recall scenes; sequence them in the act timeline (clips, gaps, scheduled MIDI/OSC). ACT triggers start/stop acts via MIDI or OSC — separate from Ableton Link tempo sync.

SCENE

Timeline Editors

Scene timeline: DMX keyframes (0-255), multi-track, snap, undo. Act timeline: scene clips with start times and gaps. See ACT_TIMELINE.md.

CLIP

Clip Launcher

Session-style grid for live performance. Assign any scene to any cell, see playing/queued/recording states, and stop everything with one button.

CLIP

MIDI Controller Templates

One-click templates for Behringer X-Touch (Mackie mode + scribble strip SysEx labels) and Akai APC40 MK1. Pitch-bend mappings, MIDI Learn for everything else, applied via UI or POST /api/midi/controller-template.

OSC

OSC Integration

Two-way OSC for Super Control, scenes, master faders, and ACT triggers. Use the in-app OSC monitor while mapping. Works with Reaper, QLab, Max/MSP, Pure Data, and any tablet OSC app you configure yourself.

SYNC

Unified Operator Surfaces

One Super Control engine on the fixture page and mobile route. Shared DmxFaderRow controls on the DMX page and a touch pinned-channel strip. Experimental stubs and duplicate touch panels removed.

NET

Art-Net Output

Professional Art-Net distribution across multiple universes. Network interface auto-detection with ICMP ping verification helps you identify USB Ethernet adapters from the Settings panel.

BRIDGE

LAN / Pi Bridge

Hosted at artbastard.aday.net.au? Run artbastard-bridge on a Raspberry Pi on your fixture LAN. The cloud UI drives Art-Net locally; optional Ableton Link on the Pi. Many browsers, one shared show.

TOUCH

Touch Surface

The #/mobile route gives you Super Control and DMX channels with a touch-first layout on phones and tablets. Hash-based deep linking everywhere.

THEME

Live Theme Tuning

HSL sliders and rack presets apply to the UI as you move them (v5.16.0). Debounced server sync via /api/appearance; Sync now and Reload UI for multi-client shows. Typography, spacing, and animation speed included.

HELP

In-App Help & Address Sheet

Press Ctrl+H anywhere or open Settings > Help. Covers DMX basics, DIP-switch calculator, MIDI/OSC, ACT triggers, factory reset, controller templates, keyboard shortcuts, troubleshooting, plus a printable PDF address sheet.

TEST

Smoke + Demo Tooling

Vitest unit tests for filtering, ACT triggers, clip launcher and scene capture. Backend smoke script (test:api-contract) plus an automated screenshot and video capture pipeline for the showcase tour.

Quick Start

  1. Clone: git clone https://github.com/aday1/artbastard.aday.net.au.git
  2. Install: npm ci && npm --prefix react-app ci
  3. Run ./start.sh (Linux/macOS) or .\start.ps1 (Windows)
  4. Open http://localhost:3030
  5. Configure your DMX interface in Settings
  6. Need a clean slate? Run with --reset / -Reset
